WindowsLockPin 0.2.0（实验版）

用途：在 Windows 11 x64 登录选项中增加 Google Authenticator 6 位动态验证码入口，同时保留原生 Windows Hello PIN。

安装前必须确认：

1. 当前登录用户是管理员，并且知道微软账户密码（不是 PIN）。
2. 原生 PIN 可以正常解锁；手机丢失或程序异常时用 PIN 回退。
3. 这是未签名的实验软件。只使用可信来源提供的安装包，并核对随包 SHA-256。
4. 凭据提供程序会进入 Windows LogonUI。虽然已在一台 Windows 11 目标机验证，其他系统配置仍可能不兼容。
5. 微软账户密码会使用 Windows 机器范围 DPAPI 加密保存，文件仅允许 SYSTEM/Administrators 访问。具有本机管理员或 SYSTEM 权限的程序仍在信任边界内。

安装完成后会打开绑定窗口：

- 输入微软账户邮箱和账户密码；
- 用 Google Authenticator 扫描二维码，或手动输入设置密钥；
- 输入手机生成的 6 位码并保存；
- 等待下一枚验证码后锁屏测试；
- 在“登录选项”中选择“Authenticator 验证码”。

二维码只用于绑定。日常解锁需要输入手机当前的 6 位验证码。

如果取消绑定窗口，登录组件虽已安装，但不会为未绑定用户显示验证码入口。原生 PIN 不受影响。

卸载：可从“设置 → 应用 → 已安装的应用”或开始菜单卸载。卸载器会询问是否同时清除加密绑定数据，默认选择保留。

适用范围：Windows 11 x64、个人微软账户、本机交互登录/解锁。不支持 RDP、UAC、域账户或强制双因素策略。
